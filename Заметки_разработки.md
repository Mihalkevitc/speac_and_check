
# Платформа 'Speak and check'

Платформа для подготовки студентов к сдаче экаменов по инорстранным языкам (англ.) с учётом международных стандартов обучения.

Основной функицонал - выполнение заданий на основе методических пособий. Ответ на задания представляет из себя голосовой ответ (возможно с последующим транскрибированием для отправки в LLM с заготовленным промптом или звукозаписью - смотря, что легче и оптимальнее анализировать). На каждый ответ при помощи LLM получается категоризированная оценка с развёрнутой обратной связью в виде пунктов списка 'Что хорошо' и 'Что требует улучшения'

# Проработка технической концепции

Уровень концепции:
- необходимо продумать выбор технологии транскрибирования речи: что лучше анализировать - звукозапись или транскрипт?
- необходимо продумать архитектуру платофрмы: монолит или микросервис
- необходимо продумать язык программирования 
  - монолит - один ЯП, зависит от транскрибирования и общения с LLM (целевой - Python); 
  - микросервис - сервисы транскрибирвоания и взаимодействия с LLM - Python, сервисы platform core - Java
- необходимо продумать подключение оплаты месячной подписки (юредическим аспектом занимается нанятый юрист)
- необходимо продумать использование API LLM - выбраная модель DeepSeek (flash или V4 - зависит от цены)

Уровень БД и хранения: 
- необходимо выбрать хранилище (PostgreSQL or S3 or someSQL or someNoSQL) (зависит от выбора хранения звукозаписи или транскрипта)
- необходимо продумать структуру БД с учётом требования оптимальности и надёжности платформы
- необходимо продумать хранения ответов студентов (транскрипт или звукозапись)

Уровень кода (бек и фронт):
- необходимо продумать структуру сущностей кода (классы)

Уровень API:
- необходимо продумать openapi-специфкации общения бека с фронтом, бека с LLM

Уровнь фронта:
- необходимо додумать и реализовать дизайн: desktop + mobile (нужна кросплатформенность google chrome + safari)

# PostgreSQL tables

Платформа разбита на категории - экзамены (exams): ОГЭ, ЕГЭ, IELTS, TOEFL

У каждого экзамена (exam) есть типовые задания (tasks - дуамю для оптимальности БД стоит разделить на OGE_tasks, EGE_tasks, IELTS_tasks, TOEFL_tasks): task 1 - прочтите вопросы и ответьте на них, task 2 - прочтите текст и...

У каждого типа задания есть конкретный экземпляр задания (task_1_examples): 4 вопроса про экогологию, 4 вопроса про семью...

Есть пользователи (user) с разными ролями (roles): 
- student - делает задания, получает оценки и обратную связь; 
- teacher - создаёт группы студентов, смотрит историю их ответов;
- admin - создаёт задания.

У каждого пользователя (user) есть личный кабинет

У каждого студента (student) есть история ответов (answer_history) на его задания (task_1_examples)

У каждого ответа (answer) есть задание (task_1_examples) и результат оценки (score) ответа

У каждого учителя (teacher) может быть группа студентов (students_groups)
